# Drum Kit

A simple, interactive web-based drum kit built with vanilla HTML, CSS, and JavaScript.

## Features
- Play various drum sounds by clicking on the drum pads or using the corresponding keyboard keys.
- Responsive design.
- Dynamic animations on key press/click.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6+)

## How to Run Locally
1. Clone the repository or download the source code.
2. Open the `index.html` file in your web browser.
3. Start playing by pressing the mapped keys on your keyboard or clicking the drum elements on the screen.

## Project Structure
- `index.html`: The main structural layout of the application.
- `style.css`: Contains all the styling and animations.
- `script.js`: Handles the logic for mapping keys/clicks to sounds and triggering animations.
- `sounds/`: Directory containing all the audio files for the drum kit.
